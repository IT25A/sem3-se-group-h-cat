# Simba: Finding Home

**Simba: Finding Home** ist ein in Unity (C#) entwickeltes 2D-Adventure, das im Rahmen des Moduls Software-Engineering entstanden ist. Im Spiel begleitest du die verirrte Katze Simba auf ihrem Weg zurück nach Hause. Das Gameplay kombiniert die Erkundung der Spielwelt, Interaktionen mit NPCs, das Sammeln von Quest-Gegenständen zum Freischalten weiterer Szenen sowie das Beachten des sinkenden Wasserstands als zeitkritische Überlebensmechanik.

## 1. Ausführung im Browser

Das Spiel kann direkt im Browser über Unity Play gespielt werden:

👉 **[Simba: Finding Home auf Unity Play](https://play.unity.com/en/games/7815bff6-6535-41fa-a5a1-31276be2fa97/simba-finding-home)**

* **Hinweis:** Das Spiel ist für den Vollbildmodus optimiert (aktivierbar über das Vollbild-Symbol unten rechts im Spielfenster).

### Steuerung
* **WASD / Pfeiltasten:** Bewegung von Simba
* **E:** Interagieren (mit NPCs sprechen, Wasser trinken, Objekte nutzen)
* **Maus:** Navigation in Menüs und Dialogen

## 2. Einsicht in den Quellcode

Alle Spielskripte sind in **C#** implementiert und befinden sich im Repository unter folgenden Pfaden:

* `CAT_GAME/Assets/Scripts`
* `CAT_GAME/Assets/UI/Scripts`

## 3. Lokales Öffnen im Unity Editor

1. **Unity Hub** sowie die verwendete Editor-Version (**Unity `6000.6.3f1`**) installieren:  
   https://docs.unity.com/en-us/hub/install-hub-win-mac
2. Dieses Repository klonen oder als ZIP herunterladen und vollständig entpacken.
3. Im Unity Hub über **Add → Add project from disk** den Unterordner `CAT_GAME` auswählen und das Projekt öffnen.
