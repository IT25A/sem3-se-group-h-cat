SIMBA
Ein 2D-Adventure-Spiel, entwickelt in Unity. Begleite eine verirrte Katze auf ihrer Reise und löse Aufgaben, um ihren Weg zurück nach Hause zu finden. #Spiellogik und Workflow Introsequenz: Ein animierter Clip zeigt, wie sich die Katze Simba beim Mäusefangen im Wald verirrt hat.

Um zu überleben, ernährt sich Simba von Trockenfutter und Wasser. Für beide Elemente gibt es im Spiel jeweils eine eigene Anzeige. Der Spieler muss 100 Trockenfutter-Stücke (Punkte) sammeln, damit Simba es nach Hause schafft.

Das Sammeln ist in Stufen (Etappen) unterteilt: Bei Erreichen bestimmter Punktzahlen erhält Simba einen Hinweis, um neue Tasks, Personen oder weiteres Futter zu finden und dem Ziel näherzukommen. Futter bekommt Simba nach jedem erfolgreich absolvierten Task. Wasser kann an Wasserquellen aufgefüllt werden.

Die Überlebens-Mechanik: Je länger der Spieler für seine Tasks benötigt, desto stärker leert sich die Wasseranzeige. Wenn die Wasseranzeige auf null fällt (kein Wasser mehr vorhanden ist), stirbt Simba und das Spiel ist beendet (Game Over).

Anfangsstand: Simba hat kein Futter (0 Punkte) und eine volle Wasseranzeige (100 %).

Der Game Flow (Spielfortschritt) Das Hauptziel: Die Katze muss insgesamt 100 Futterstücke sammeln, um genug Energie für den Weg nach Hause zu haben.

Die Meilensteine: Das Spiel ist in Etappen unterteilt. Sobald eine bestimmte Anzahl an Futterstücken erreicht ist, schaltet der Spieler einen wichtigen Story-Hinweis für das nächste Gebiet oder die nächste große Aufgabe frei.

Etappe 1 (Ziel: 10P)

Situation: Die Katze startet mit 0 Futterstücken und weiß nicht, wohin sie gehen soll.

Die Aufgabe: Eine NPC-Katze bittet Simba, einen Blumenstrauß zusammenzustellen (z.B. durch das Finden von 3 versteckten Blumen im Startgebiet)(10P).

Hinweis: "Wenn du Durst hast, findest du an Wasserquellen frisches Wasser. Das ist sehr wichtig für dein Überleben."

Etappe 2 (Ziel: 25P)

Situation: Simba trifft auf die nächste NPC-Katze (einen Bauern).

Die Aufgabe: Eier unbeschadet von der einen Straßenseite über das Wasser auf die andere Seite bringen (+15P).

Hinweis: Der Bauer sagt: "Ich habe deine Maus gesehen. Sie ist in diese Richtung gelaufen, geh mal zu XY."

Etappe 3 (Ziel: 50P)

Aufgabe 1: Die entlaufene Maus fangen (+15P).

Situation: Eine NPC-Katze hat ihren Schlüssel verloren. Simba kann ihr auf verschiedene Arten helfen:

Option A: Holz sammeln und ein Feuer entfachen, um der Katze während des Wartens Wärme zu spenden (+10P).

Option B: Den verlorenen Schlüssel finden (+15P).

Option C: Eine Rätselfrage der NPC-Katze lösen (+20P).

Hinweis: "Finde dein Halsband, damit man dir weiterhelfen kann."

Etappe 4 (Ziel: 70P)

Aufgabe 1: Das verlorene Halsband finden (+10P).

Aufgabe 2: Eine NPC-Katze ist verletzt. Simba bringt sie sicher zu einem Tierarzt (+15P).

Hinweis: Der Tierarzt kann Simbas Halsband lesen und so den Besitzer ermitteln.

Etappe 5 (Ziel: 100 Punkte)

Situation: Der Tierarzt ist bereit, Simbas Besitzer zu kontaktieren, verlangt dafür aber eine Gegenleistung.

Aufgabe 1: Ein Heilmittel (eine seltene Pflanze) besorgen. Dafür muss Simba erfolgreich durch ein Labyrinth navigieren (+20P).
